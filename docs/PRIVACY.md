# Privacy

Monzo Bot is independent and unofficial. Financial data stays in Android app-private no-backup storage encrypted with Android Keystore AES-GCM. Google access tokens stay in memory. The same original financial file/alias/envelope and provider credential slots are retained for compatible in-place updates. Corrupt/unsupported data fails closed; it is not silently reset.

Google authorization grants read-only Sheets and Drive metadata access. Discovery lists spreadsheet metadata; source cells are read only after explicit selection. Source exports are never modified. No hard-coded personal spreadsheet ID, transaction, account identifier, API key or signing key is included in source.

Ask shares the typed question and bounded locally computed facts with the explicitly selected OpenAI or Anthropic provider after named per-request consent. Labels require separate opt-in. Notes, addresses, receipts, Pot names and source IDs stay out of tool results. Anything manually typed into a question is sent as written. AI plan preparation separately shares only the approved planning message/reference date and application instructions, with no imported transaction/budget context. Provider calls are user-triggered, bounded and have no automatic retries. API charges and provider processing/retention follow the selected account and provider terms; no zero-retention or chat-subscription allowance claim is made.

Remembering a provider key is optional. Each provider has its own encrypted no-backup credential file and alias; keys are excluded from financial JSON, exports, app-generated prompts, logs and saved view state. Switching providers does not carry consent or another provider's key. Forget selected/all keys is explicit. Deleting the workspace invalidates queued edits and pending auth/voice/import acceptance, cancels check-ins and clears financial/provider storage. An in-flight HTTP request or separately approved external file write may already have reached its destination and cannot be unsent.

Voice uses a supported Android on-device recognizer only after contextual permission. There is no cloud fallback or app-created recording file. A transcript remains editable; sending it to an AI provider requires the separate AI approval. Financial screens use Android FLAG_SECURE. Generic notification/widget content contains no amounts, merchants or categories. Device/platform restrictions and compromised devices remain outside these protections.

Plaintext JSON export requires deliberate destination selection and a warning; exported files are no longer protected by this app. Separately approved notes/calendar handoffs show minimal draft fields, exclude original wording/sourceIDs and start with amounts off. The destination application may sync reviewed content under its own account policies. No automatic calendar save or message is made. Disconnect stops device access and clears cached tokens; Google grants can separately be revoked in Google Account settings.

No analytics, ads, hosted financial database or background AI is configured. Real device Keystore/backup/lifecycle behaviour and live Google/provider acceptance still require verification before a public product release.

## Just-in-time AI permission notice

Before enabling a request's processing permission, the app names the selected provider and shows Continue and Cancel. Continue only enables the existing Send action; it does not contact the provider or save a key. Cancelling leaves processing disabled. Changing the provider, key, model, message, label-sharing choice or relevant source context invalidates the permission/review.

For Ask, the disclosure includes the question as written, reference/retrieval dates, and bounded read-only tool results that may contain individual transaction amounts/dates, spending totals, budgets, user-reported balance/reserve and commitment amounts/due dates. Merchant/category/type and plan labels require the separate label-sharing choice. This is not merely anonymous aggregate data. Raw source notes, addresses, receipts, Pot names and original transaction IDs are excluded from tool output, but anything the user types may contain private information.

For AI plan preparation, the notice instead states that the approved message, reference date and draft instructions are sent, not imported financial context. The user's API key authenticates requests only to the selected provider endpoint. API usage is charged according to that account; training and retention depend on the provider's applicable policies and settings, not a guarantee made by this app. Existing provider-specific optional key storage remains separate.
